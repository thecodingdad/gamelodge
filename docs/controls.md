# Controls

GameLodge is built for the controller: every screen works with a gamepad alone, with button hints for the
controller in your hand. Touch, mouse and keyboard work everywhere as well.

| Page | What it covers |
|---|---|
| [Controllers & shortcuts](controllers.md) | Every controller's own layout and settings, button shortcuts, shortcuts in other apps, touch, mouse & keyboard |
| [Mouse emulation](mouse.md) | A mouse pointer on the stick for apps without controller support |
| [Quick menu](quick-menu.md) | Volume, Wi-Fi, hosts, controllers and Home Assistant over every game and stream |

In a stream every controller is passed to the host as its own gamepad, and the same shortcuts and quick menu
work there too.
