# GameLodge

**All your games in one controller-first launcher – local, streamed and emulated.**

GameLodge is a game launcher for Android handhelds, tablets, TVs and Windows PCs. It puts the games
installed on the device, the games of your streaming PCs and your emulated games into one library with
artwork and metadata, and starts each one the right way: locally, through an emulator or as a stream from
Sunshine, Apollo or Vibepollo.

## Built for the controller

Every screen works with a gamepad alone, with button hints for the controller in your hand. Touch, mouse
and keyboard work everywhere as well, so the same launcher fits a handheld, a tablet on the couch, a TV
and a desk PC.

## Platforms

| | Android | Windows |
|---|---|---|
| Version | Android 10 or newer | Windows 10 or 11 (x64) |
| Local games | Android apps and games, emulated ROMs | Steam, Epic, GOG, Xbox, EA, Ubisoft, Battle.net, Amazon and more, emulated ROMs, your own games |
| Streaming client | Built in (Artemis) | Built in (Moonlight) |
| Xbox home streaming | Built in | Built in (WebView2 player window) |
| Streaming host | – | The PC shares its games with your other devices |
| Home screen | Can replace the Android home app | Full-screen launcher, tray, autostart |
